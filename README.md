# ديوانية ق

منصة متابعة العادات اليومية لطلاب أكاديمية ق — بدورين (طالب، مشرف) بالإضافة إلى لوحة إدارة.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000).

## حساب الإدارة الافتراضي

يُنشأ تلقائيًا عند تشغيل `prisma db seed` (يتم تلقائيًا مع أول migration)، بالبريد والاسم وكلمة المرور المحددة في ملف `.env` المحلي (`ADMIN_EMAIL` و `ADMIN_PASSWORD`) — هذا الملف غير مرفوع في git عمدًا لأنه يحتوي بيانات حساسة.

لتغيير كلمة مرور الإدارة: عدّل `ADMIN_PASSWORD` في `.env` ثم شغّل `npx prisma db seed` مرة أخرى لتحديثها في قاعدة البيانات.

## كيف يعمل النظام

1. يسجّل الطالب/ولي الأمر حسابًا من `/signup` بالبريد وكلمة المرور → يبقى الحساب "بانتظار الموافقة".
2. تدخل أنت (الإدارة) على `/admin` بحساب الإدارة أعلاه، وتحدد دور كل حساب (طالب / ولي أمر / مشرف)، وتربط كل ولي أمر بأبنائه من نفس الصفحة.
3. بعدها يستطيع كل مستخدم الدخول ورؤية واجهته الخاصة تلقائيًا.

المهام الخمس الافتراضية (صلاتين جماعة، ورد صفحة، وتر ركعة، قراءة ١٠ صفحات، سماع المقطع أسبوعيًا) مُجهّزة مسبقًا، ويمكن للمشرف تعديلها أو إضافة غيرها من `إدارة المهام والنقاط`.

## قاعدة البيانات والملفات

- قاعدة البيانات SQLite محلية في `prisma/dev.db` (تُنشأ تلقائيًا، غير مرفوعة في git).
- ملفات إثبات المهام يرفعها الطلاب وتُحفظ في `public/uploads/proofs/`.

## أوامر مفيدة

```bash
npx prisma studio      # تصفح قاعدة البيانات بواجهة رسومية
npx prisma db seed     # إعادة تجهيز حساب الإدارة والمهام الافتراضية
npx tsc --noEmit        # فحص الأنواع
```
